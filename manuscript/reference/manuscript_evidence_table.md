# DART Manuscript: Evidence Table

Every manuscript claim traces to a specific experiment, a headline number, and a source
file. **No claim may exceed its evidence.** Allowed / forbidden wording is binding on all
drafting. All numbers are from FULL runs on the server (`ssh:139.180.131.202`,
`/data/boom/DART`, conda env `Agent`) unless marked otherwise.

**Provenance note (HIR-Bench):** the headline HIR-Bench numbers below are from the FULL
13,440-cell run. The CSVs at `results/exp11_hir_benchmark/` are a later QUICK reproduction
(144 cells, AUC 0.5) that overwrote the original FULL outputs, and no FULL artifact
survived. The FULL predictability AUC was therefore regenerated on 2026-07-12 by a lean
method-independent runner (`results/_audit/fig6f_roc_lean.py`, mirrored at
`upgrade/fig6f_roc_lean_runner.py`) that reproduces the identical 13,440-cell grid with the
same seeds and calls the shipped `predictability_auc` (default 4 disagreement features,
leave-one-grid_id-out CV). It skips only the per-method retrieval-scoring loop, which the
AUC does not use. Reproduced value: **AUC 0.640** (n_pos 8640 / n_neg 4800), top feature
`topk_disagreement`. Cite this FULL value, not the on-disk QUICK CSV (AUC 0.5, n_pos 48 /
n_neg 96). The 0.005 difference from the earlier-cited 0.645 reflects the lost original
FULL run; 0.640 is the current reproducible number.

## Claim 1: Method unification (strongest, least refutable)

**Statement.** Under the implemented cosine kernel, CMap-style mean-signature retrieval is
*numerically identical* to DART's collapsed mean-cosine objective. More broadly, signature
retrieval occupies the mean-collapsed (zero-variance) end of a distributional-retrieval
spectrum that DART generalizes.

| item | value | source |
|---|---|---|
| exp08 Hit@1 `mean_cosine` | **0.3885** (0.388492) | `results/exp08_signature_baselines/summary.csv` |
| exp08 Hit@1 `cmap_cosine` | **0.3885** (0.388492), identical | same |
| exp08 Hit@1 `cmap_wtcs` (rank-based) | 0.4635, *differs* | same |
| exp08 Hit@1 `global_energy` (DART) | 0.8369 | same |
| Source-code confirmation | `src/baselines/cmap_signature.py`: `scoring='cosine'` computes cosine of mean-delta signatures; identical operation to `score_mean_cosine` | verified line-by-line |

**Limitations.** The identity is exact only for the cosine connectivity kernel. Canonical
L1000 WTCS is a **rank-based (GSEA-style) enrichment** of the same mean-collapsed signature
,  monotone in the same quantity but **not algebraically identical** to DART's cosine.

**Allowed wording.** "CMap-style cosine retrieval is a collapsed mean-signature special
case of the broader DART retrieval family." / "Mean-signature retrieval is the
zero-variance limit of distribution-aware retrieval."

**Forbidden wording.** "All CMap methods are identical to DART." / "WTCS is mathematically
identical to DART." Always clarify WTCS is a rank-based variant of the same paradigm, not
an algebraic identity.

## Claim 2: Information-conditioned advantage

**Statement.** Distribution-aware retrieval improves ranking when candidate response
populations carry real subpopulation-resolved structure, but not when candidate responses
are generated by mean-only or isotropic predictors.

| item | value | source |
|---|---|---|
| exp08 Hit@1 DART (`global_energy`) | **0.837** | `exp08/summary.csv` |
| exp08 Hit@1 mean/CMap (`mean_cosine`=`cmap_cosine`) | **0.389** | same |
| exp08 Hit@1 `pca_dist` (latent distributional) | 0.778 | same, effect is not a raw gene-space artifact |
| exp08 Hit@1 `coverage_mean` / `coverage_worst` | 0.773 / 0.589 | same |
| exp09 nDCG delta, `average_effect` predictor | **−0.004** | `exp09_predict_then_rank/` |
| exp09 nDCG delta, `nearest_neighbor` predictor | **−0.097** | same |
| exp09 nDCG delta, `scgen` (cpa_linear fallback) | **−0.029** | same |
| exp09 diag: real vs predicted `subpop_var_ratio` | **0.046 vs 0.009** (≈5×) | `exp09_structure_diagnostics/` |
| exp09 diag: real vs predicted `response_diversity` | **0.158 vs 0.057** (≈2.7×) | same |
| exp09 diag: predicted vs real `isotropy_index` | **0.998 vs 0.959** | same |

**Limitations.** exp09's "candidate populations" are *predicted*; the negative result is a
property of predictor collapse, not of any specific published predictor. The scGen result
uses an in-repo CPA-linear fallback (real scGen unbuildable on this toolchain), stamped in
provenance, it is representative of latent-linear predictors, not a scGen benchmark.

**Allowed wording.** "DART's advantage depends on the information condition of the
candidate response source." / "Predictor-collapsed candidate populations erase the
distributional advantage."

**Forbidden wording.** "DART improves any perturbation predictor." / "DART is a universal
downstream decision layer."

## Claim 3: HIR-Bench diagnostic framework

**Statement.** HIR-Bench provides a method-neutral framework for evaluating heterogeneous
inverse retrieval under three information conditions, `observed`, `predicted_mean`,
`predicted_structure`, with an analytical flip boundary and a latent welfare oracle.

| item | value | source (FULL 13,440-cell run, artifact) |
|---|---|---|
| grid size (FULL) | **13,440 cells** | `exp11_hir_benchmark/` (artifact) |
| sanity: `no_conflict_flip_rate` | **0.0000** (≤0.05 pass) | `sanity_checks.csv` (FULL) |
| sanity: `median_boundary_margin` | **0.2917** (≤1.0 pass) | same |
| sanity: `predicted_mean` DART−mean gap | **0.0507** (≤0.10 pass) | same |

**Forbidden wording.** "Failure risk is accurately predicted." / "HIR-Bench proves DART is

## Claim 4: Boundary audit / honest limitation (the signature contribution)

**Statement.** DART shows strong, significant gains under an energy-based proxy objective,
but **oracle-independent** utility metrics do not yet support a universal therapeutic
recommendation claim, and the diagnostic gate does not sharply concentrate the proxy
advantage into its recommended subset.

| item | value | source |
|---|---|---|
| exp12 FULL scale | 6,885 perf rows, 765 diagnostic queries | `exp12_partial_observed_retrieval/` |
| recommendation distribution | 621 `DART_recommended` / 133 `mean_or_no_call` / 11 `mean_sufficient` | `information_condition_summary.csv` |
| Go-1: `DART_coverage_worst` median regret reduction | **+0.119** | `go_nogo_report.md` |
| Go-1: Wilcoxon p | **4.26e-56** | same |
| Go-1: fraction of queries improved | **72%** (n=621) | same |
| Non-circular nDCG (MoA-recovery) gain on recommended | **−0.013** (negative) | same |
| Non-circular minority-coverage gain | ≈ 0 (+0.005) | `recommendation_vs_outcome.csv` |
| exp13: real tasks DART-dominant under non-circular criterion | **0 / 37** | `exp13_real_data_projection/projection.csv` |
| Gate discrimination: recommended vs non-recommended median regret | **+0.119 vs +0.122** (does not separate) | `go_nogo_report.md` |
| Verdict | **CONDITIONAL-GO (metric-dependent)** | same |

**Limitations.** The energy-welfare regret proxy is aligned with DART's own objective
(energy/MMD distance), so its gains carry circularity risk. This is the reason the claim is
framed as metric-dependent, not universal.

**Allowed wording.** "Distributional gains are metric-dependent and should be diagnosed
before use." / "Under an energy-based proxy DART reduces decision regret; under
oracle-independent metrics the advantage is not yet demonstrated."

**Forbidden wording.** "DART provides better therapeutic recommendations." / "DART improves
oracle-independent therapeutic utility."

## Cross-cutting rules

1. **exp09 is a boundary result, never hidden.** It is the mechanism that makes Claim 2
   credible, present it as "information condition explains predictor failure," not as a
   negative buried in supplement.
2. **exp12 non-circular nulls are reported in the main text**, adjacent to the energy-proxy
   positives. Do not report the +0.119 without the −0.013.
3. **exp15 is exploratory throughout**, every mention carries the qualifier and the
   longitudinal-data limitation.
4. **No therapeutic-superiority language anywhere.** DART is a reliability-aware decision
   framework, not a recommender.
