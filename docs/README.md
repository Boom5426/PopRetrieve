# PopRetrieve project website

The [project website](https://boom5426.github.io/PopRetrieve/) is a static site with no build step.

Preview from the repository root:

```bash
python3 -m http.server 8000 --directory docs
```

Open `http://localhost:8000`. GitHub Pages serves the `docs/` directory on `main`.

The page links to the current manuscript, SI, code and datasets. Keep `assets/fig1_overview.png` in sync with the repository's overview image.
