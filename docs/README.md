# PopRetrieve project website

This directory is a dependency-free static project website for GitHub Pages.

To publish it, in the GitHub repository open **Settings → Pages**, select **Deploy from a branch**, then choose `main` and the `/docs` folder. GitHub will serve the page at the repository's GitHub Pages URL.

The page links to the canonical GitHub repository, manuscript, citation metadata and Hugging Face data release. `assets/fig1_overview.png` is a deployment-local copy of the overview figure used by the page.
