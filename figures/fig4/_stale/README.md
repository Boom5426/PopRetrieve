# Stale panel scripts (old HIR-Bench 6-panel composite)

Figure 4 (the composite "criterion decides" figure) is assembled from
fig4b (analytic boundary), fig4f (circularity 2x2), fig4_shape (oracle shape),
fig4_gate2 (Gate 2) and the two fig7_natural panels (Gate 1, premise); see
fig4_assemble.py. These four scripts are the OLD six-panel HIR-Bench version
whose panels (generative schematic, Hit@1/advantage grid, method dominance,
sanity checks) moved to Extended Data. They are not imported by fig4_assemble
and are archived here, not deleted.

The four PNGs here keep the panel numbering they were exported under. They are an
archive, so they are not renumbered when the main deck is.
