# Per-panel source data

These files exist so a reader can check a figure without re-running an experiment.

**They are not all the same kind of file, and until 2026-07-27 nothing said so.** Four of them had
drifted away from the numbers their panels plot, and two of those shipped values this project has
retracted: the pre-sentinel-fix MoA-nDCG sample sizes from CORRECTIONS.md R2, and the 37-row QUICK
subset behind the retracted "0 of 37" of R13. In each case the panel was right, because panels read
`results/` directly, and the file offered to check the panel was wrong. `figures/sync_source_data.py`
now regenerates the copies and fails loudly on drift; run it after any experiment that rewrites the
files below.

```bash
python figures/sync_source_data.py            # rewrite every mirror from its live parent
python figures/sync_source_data.py --check    # exit 1 on drift, write nothing
```

## The three kinds

| kind | what it is | who owns it |
|---|---|---|
| **PRIMARY** | a panel reads this file itself, so it *is* the input and has no upstream | edit deliberately; nothing regenerates it |
| **MIRROR** | a byte-for-byte copy of one file under `results/` | `sync_source_data.py`. Never edit by hand |
| **DERIVED** | a hand-built view of one `results/` file: a column projection, a filtered subset, or hand-entered constants | edit deliberately; the sync script only checks that the parent still exists |
