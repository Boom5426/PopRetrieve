# Stale / superseded source-data files

These CSVs are archived (not deleted) because they are superseded by earlier
figure-deck reorganisations. Each was verified to be referenced by NO current
figure or Extended-Data script (neither a pandas read_csv nor a "Source data:"
comment), and each corresponds to an OLD figure numbering that no longer matches
the final manuscript (e.g. fig6_A_zero_spread_limit.csv actually holds the
zero-variance-collapse data, which is now Extended Data Fig. 1d;
fig5g_conditional_advantage.csv is a panel of the two-gate figure, now Figure 5,
under its pre-renumber name). Archived names are never renumbered when the main
deck is: that is the point of the archive. The canonical current source-data files for
each final panel remain in the parent directory.
