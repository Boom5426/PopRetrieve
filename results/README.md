# Results

This directory contains the compact result tables used by the manuscript, figure source data and reproducibility checks. The tables are derived artifacts, not a replacement for the source datasets.

The public staging includes:

- headline summaries for the core retrieval, baseline, predictor, natural-tissue and Tahoe analyses;
- Phase-II eligibility, oracle, prediction, bottleneck and gate tables;
- estimator-audit ledgers and the current audit outputs;
- the partial-observation per-query table required by the reported decision analysis.

Large per-query/intermediate dumps, local backups, logs and GDSC workbooks are excluded. Re-run commands are documented in the root [`README.md`](../README.md), while dataset placement is specified in [`DATA.md`](../DATA.md).

The authoritative interpretation of revised numbers is [`CORRECTIONS.md`](../CORRECTIONS.md), followed by [`docs/FINDINGS.md`](../docs/FINDINGS.md) and the Phase-II documents.
